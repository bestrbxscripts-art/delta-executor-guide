# Delta Executor reference · EN / PT-BR

Independent documentation about reading platform and release information for Delta Executor for Roblox, with reusable release records and problem-report templates.

This project documents how to organise evidence. It does not distribute executables, run scripts, certify downloads or report application compatibility tests.

## Read the documentation

- [English reference](https://bestrbxscripts-art.github.io/delta-executor-guide/)
- [Referência em português do Brasil](https://bestrbxscripts-art.github.io/delta-executor-guide/pt-br.html)

## Reusable templates

- [Release record / ficha de versão](release-record.txt): keep versions, platforms, source URLs and dates separate.
- [Problem report / relato de problema](problem-report.txt): describe the component, exact message and observed result.

Both templates include English and Brazilian Portuguese fields. Leave unknown details marked as unknown. Remove passwords, session cookies, personal keys and private logs before sharing anything.
